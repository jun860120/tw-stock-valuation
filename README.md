# 台股估價儀表板

一頁式台股估價工具：把「估價法 × 歷史位階 × 部位控制」三件事合成一個畫面。

👉 **開啟網站**：本 repo 啟用 GitHub Pages 後，網址為 `https://<你的帳號>.github.io/<repo 名稱>/`

## 功能

- **四種估價法**：本益比法、股價淨值比法、殖利率法（歷史分位）、殖利率法（固定 16／20／32 倍）
  - 每一列可點選「納入／排除」綜合評價
- **綜合燈號**：可買進價（含安全邊際）／合理價／昂貴價 + 旗幟量尺顯示現價落點
- **近四季 EPS 趨勢箭頭**：▲▲ ≥+20%、▲ ≥+5%、▬ ±5%、▼ ≤−5%、▼▼ ≤−20%
- **價格位階**：現價在近 N 年收盤價分布的百分位 → 價值區／升溫區
- **位階計算機**：輸入資金與分批次數 → 算出今天建議買幾股（位階越低單筆越大）
- **樂活五線譜**：對數回歸趨勢線 ±1SD／±2SD
- **自選清單**：畫面上「＋」直接輸入代號即可新增，資料即時抓取，存在瀏覽器本機
- **即時報價**：盤中每 60 秒更新（證交所 MIS）

## 內建防呆

| 機制 | 說明 |
|---|---|
| 價值陷阱警示 | 估值「便宜」但近四季 EPS 年增 ≤ −10% 時跳警告 |
| 成長股提醒 | 估值「昂貴」但 EPS 年增 ≥ +25% 時提示縮短回看年數 |
| 股本變動還原 | 偵測分割／面額變更（相鄰交易日跳動 >±35%），歷史股價與 EPS 自動回溯校正 |
| 歷史帶失效偵測 | 現值偏離歷史中位數 2 倍以上的估價法自動排除 |

## 資料來源

- FinMind 開放 API：每日 PER／PBR／殖利率、收盤價、單季 EPS、股票基本資料
- 證交所 MIS：盤中即時報價（透過公用 CORS 代理；若代理無法連線會自動退回盤後收盤價）

## 使用方式

手機開啟網址後，iPhone 選「分享 → 加入主畫面」、Android 選「選單 → 加到主畫面」，即成為全螢幕 App。
